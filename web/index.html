☁️ Cài Đặt Đám Mây Trực Tuyến (Google Firebase)

Khi kết nối với Google Firebase Realtime Database (Hoàn toàn miễn phí), mọi nội dung, bài học, bìa sách và âm thanh bạn chỉnh sửa sẽ tự động đồng bộ thời gian thực sang máy tính và điện thoại của tất cả học sinh!

Trạng thái kết nối hiện tại: Chưa kết nối đám mây (Dùng bộ nhớ cục bộ)
1
Tạo dự án Firebase miễn phí: Truy cập console.firebase.google.com (đăng nhập bằng tài khoản Google của bạn) và bấm Add project.
2
Bật Realtime Database: Vào menu bên trái chọn Build -> Realtime Database -> Create Database, chọn vị trí (Singapore/US) và chọn tab Rules đặt ".read": true, ".write": true (Test mode).
3
Lấy cấu hình Web App: Bấm biểu tượng bánh răng ⚙️ Project Settings -> General -> Your apps, bấm biểu tượng web </>, copy toàn bộ đoạn mã firebaseConfig = { ... } rồi dán vào ô bên dưới:
